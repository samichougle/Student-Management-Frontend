# Student Management System — Frontend

A Student Management System frontend built as a **learning project** using Next.js, TypeScript, Tailwind CSS, and modern React tools.

The goal of this project was not to build a production-ready student management platform, but to learn how to structure and build a real-world full-stack application.

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* shadcn/ui
* React Hook Form
* Zod
* Axios
* TanStack React Query
* Framer Motion

## What I Built

* Dashboard
* Student management
* Student search and pagination
* Add/edit student forms
* Authentication flow
* API integration
* Responsive layouts
* Form validation
* Reusable components and services

## What I Learned

This project taught me much more than I originally expected:

* Building applications with the **Next.js App Router**
* Working with **TypeScript** in a real project
* Creating reusable components and UI systems
* Building responsive interfaces with Tailwind CSS
* Form handling and validation with React Hook Form and Zod
* Connecting a frontend to a REST API
* Organizing code into clear and maintainable structures
* Separating UI, services, types, and utilities
* Debugging frontend, API, hydration, and TypeScript issues
* Thinking about **clean code and scalable project structure**
